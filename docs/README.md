## وضعیت محیط‌ها (۲۰۲۶-۱۱-۲۱)

| بک طرح الهی (Strapi) | **روی سرور فعال**؛ نسخهٔ سرور از شاخهٔ `master` همان مخزن |

## اجرای محلی بای‌مانی

پیش‌نیاز: .NET 10 و PostgreSQL. اتصال، JWT و کلیدهای سرویس را در env/secret بگذارید؛ مقدار محرمانه در سند یا Git نمی‌رود.

```powershell
dotnet restore ByeMoney.sln
dotnet build ByeMoney.sln
dotnet run --project src/ByeMoney.API -- --environment Development
dotnet test src/ByeMoney.UnitTests/ByeMoney.UnitTests.csproj
```

آزمون‌های PostgreSQL با `BYEMONEY_CART_PG_TESTS=1` و `BYEMONEY_TEST_CONNECTION_STRING` فعال می‌شوند. Skip یا نبود اتصال، قبولی آزمون نیست.

## نگهداری اسناد

- هر موضوع فقط یک مرجع دارد؛ برای شاخه یا چت، سند موازی نسازید.
- سند تازه فقط وقتی ساخته می‌شود که مرجع موجود جای درستش نباشد. پلن اجراشده و گزارش بازبینی به `docs/archive/` می‌رود.
- ردیف انجام‌شده از `TASKS.md` و `HOTFIXES.md` حذف می‌شود؛ شاهدش در گزارش شواهد می‌ماند.
- تاریخچهٔ جزئی در Git است؛ فهرست فایل‌های تغییرکرده و شرح تلاش ابزارها سند نمی‌شود.
